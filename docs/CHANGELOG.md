# Startpage 更新日志

## 2026-09-07 热榜容灾与角落按钮动效

- 热榜接入 RSS 兜底：为知乎、微博、百度各配置 3 个实测可用的公共 RSSHub 源，官方 API 取数失败时依次切换，原 vvhan 聚合接口降为最后兜底，避免热榜整体不可用。
- 新增通用 RSS 解析逻辑，支持 CDATA 与常见 HTML/数字实体转义；微博、知乎、百度分别映射到微博搜索页、知乎问题页与百度搜索直链。
- 右下角操作按钮动效参考 morphicons 改版：悬停时图标平滑形变——便签→铅笔、热榜→趋势上升、账号→账号管理、设置齿轮旋转 180°。
- 入场动画柔化为淡入上浮并依次错开 60ms，移除原先的弹跳、摇摆、果冻等夸张动效。

## 2026-06-20 天气优化

- 修复风速显示 bug：12-19 km/h 错误显示为"微风"，改为正确的"和风"。
- 去掉每次请求附带的时间戳参数，恢复 Cloudflare 缓存，相同坐标 30 分钟内直接命中缓存。
- 浏览器定位从两次串行重试改为单次调用（8 秒超时），后端已有 IP 兜底，减少等待时间。
- 当 IP 定位已返回城市名时，跳过反向地理编码请求，省去 100-300ms 额外延迟。
- 修复未加载天气时显示的占位文案"线条"为"获取失败"。
- 提取城市后缀拼接逻辑为独立函数，天气图标映射改为数据驱动。
